# 🍒 Tutti Frutti Multijugador

¡Bienvenidos a la versión multijugador del clásico Tutti Frutti! Compite con tus amigos en tiempo real.

## 🚀 Jugar Online
Puedes entrar a jugar directamente aquí:
👉 [https://juego-tutti-frutti-multijugador.onrender.com](https://juego-tutti-frutti-multijugador.onrender.com)

## ✨ Características Principales
* **Multijugador Real:** Crea salas privadas y compite con amigos.
* **Ruleta de la Suerte:** Niveles de dificultad con letras aleatorias.
* **Sistema de Revisión:** Puntaje automático y revisión cruzada al finalizar.
* **Chat en vivo:** Comenta la partida mientras juegas.
* **Estética Neón:** Interfaz moderna, adaptada a cualquier dispositivo.

## 🛠️ Tecnologías
Desarrollado utilizando:
- **Node.js**
- **Socket.io** (para la magia del tiempo real)
- **Express**
- **HTML/CSS/JS**
